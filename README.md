# MedAgent: An Agentic AI Framework for Emergency Severity Prediction and Smart Hospital Queue Management

MedAgent is an AI-powered framework that combines machine learning, simulated IoT monitoring, and priority queue algorithms to predict emergency severity and optimize hospital queue management.

## 📌 Overview
MedAgent is an AI-driven healthcare system designed to predict patient emergency severity and optimize hospital queue management. The system combines machine learning, simulated IoT-based patient monitoring, and agentic AI techniques to prioritize patients according to their medical condition, enabling faster treatment and efficient resource utilization.

---

## ✨ Features

- Emergency severity prediction using machine learning.
- Smart hospital queue management based on patient priority.
- Simulated IoT monitoring for real-time patient vital signs.
- Agentic AI framework for autonomous decision-making.
- Priority-based scheduling to reduce patient waiting time.
- Visualization and analysis of patient status.
- Scalable architecture for future integration with wearable devices and hospital systems.

## ⚙️ System Workflow

1. Patient data is collected from simulated IoT sensors.
2. Vital signs are preprocessed and analyzed.
3. A machine learning model predicts emergency severity.
4. The Agentic AI module determines patient priority.
5. A Priority Queue algorithm schedules patients dynamically.
6. Healthcare professionals receive prioritized information for treatment.
